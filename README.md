# Call Dashboard - Week 2

An in-memory Call Management System developed in Java.

## Features Implemented
- In-memory data repository with SeedData
- Data models for Calls and Notes
- Layered architecture (Model, Repository, Service)
- Retrieval of active calls (excluding archived)
- Call lookup by ID including notes
- Archive call functionality

## How to Run
Run `Main.java` located at `src/main/java/com/aircall/dashboard/Main.java`.

## Known Limitations
- Data persistence is strictly in-memory (resets on restart).
